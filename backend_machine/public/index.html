Catatan Pembacaan Data

Identitas mesin: UUID dan IP diambil dari machineinfo. Nama mesin manual dan lokasi disimpan di tabel machine_setting_manual agar data asli mesin tidak berubah.
Produktivitas: memakai ProcTime sebagai Running Time. Power On Duration tetap ditampilkan sebagai durasi mesin menyala.
Downtime: dihitung dari Power On Duration - Running Time. Jika hasil minus, dashboard akan menampilkan 0.
CRUD manual: tombol Edit menyimpan custom name dan location melalui endpoint /api/machine-settings.
Source: SQL Server sewingiot · Dashboard live dari API Go.
